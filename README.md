# Polymarket BTC Trading Bot (Real-Time)

Торговый бот для Polymarket — торгует прогнозами на BTC, используя real-time данные с Binance через WebSocket для опережения рынка.

## Архитектура

```
Binance WebSocket (4 потока одновременно)
  ├── aggTrade       → поток сделок, CVD, детекция китов
  ├── kline_1m       → свечи 1 мин, RSI, EMA, VWAP
  ├── kline_5m       → свечи 5 мин, MACD, подтверждение
  └── depth20@100ms  → стакан top-20, имбаланс bid/ask
         │
         ▼
┌──────────────────────────┐
│   LiveMarketState        │  ← единый in-memory стейт, обновляется непрерывно
└────────┬─────────────────┘
         │
         ▼ (каждые 5 сек)
┌──────────────────────────┐
│   Strategy + Signals     │  ← оценка направления → поиск edge на Polymarket
└────────┬─────────────────┘
         │
         ▼
┌──────────────────────────┐
│   Polymarket CLOB API    │  ← исполнение ордеров (FOK market orders)
└──────────────────────────┘
```

## Опережающие индикаторы (Leading)

Эти индикаторы реагируют **до** движения цены и имеют наибольший вес в модели:

| Индикатор | Вес | Что показывает |
|---|---|---|
| **Order Book Imbalance** | 3.0 | Дисбаланс bids vs asks в стакане. Bids >> asks → цена пойдёт вверх |
| **Trade Flow / CVD** | 3.0 | Соотношение агрессивных покупок к продажам за 1 мин |
| **Whale Detection** | 2.5 | Крупные сделки >$50K. Кит покупает → сигнал на рост |

## Подтверждающие индикаторы (Confirming)

| Индикатор | Вес | Таймфрейм |
|---|---|---|
| RSI(14) | 1.5 | 1m |
| EMA(9/21) crossover | 1.5 | 1m |
| MACD(12,26,9) | 1.5 | 5m |
| VWAP deviation | 1.5 | session |
| Momentum | 1.0 | 5m |

## Как работает

1. **WebSocket стрим** — 4 потока данных с Binance обновляют `LiveMarketState` в реальном времени
2. **Оценка каждые 5 сек** — модель анализирует все индикаторы и оценивает P(BTC UP)
3. **Поиск edge** — сравнивает свою оценку с ценами YES/NO на Polymarket
4. **Urgency scoring** — чем сильнее согласуются leading-индикаторы, тем быстрее и крупнее сделка
5. **Исполнение** — FOK ордер через CLOB API с контролем позиции и cooldown

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Отредактируйте .env — добавьте приватный ключ кошелька Polygon
```

## Использование

```bash
# Посмотреть текущий анализ BTC (все индикаторы)
python main.py snapshot

# Показать активные BTC-рынки на Polymarket
python main.py markets

# Запустить один цикл оценки (REST)
python main.py once

# Запустить бота в непрерывном real-time режиме
python main.py run
```

## Конфигурация (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `POLYMARKET_PRIVATE_KEY` | Приватный ключ Polygon кошелька | — |
| `POLYMARKET_FUNDER_ADDRESS` | Адрес кошелька | — |
| `MAX_POSITION_SIZE` | Макс. размер позиции (USDC) | 10.0 |
| `MIN_EDGE` | Мин. преимущество для входа | 0.03 |
| `DRY_RUN` | Режим без реальных сделок | true |
| `SIGNAL_EVAL_INTERVAL` | Как часто оценивать сигналы (сек) | 5.0 |
| `MARKET_REFRESH_INTERVAL` | Обновление рынков Polymarket (сек) | 120 |
| `TRADE_COOLDOWN` | Пауза между сделками на одном рынке (сек) | 30 |
| `LARGE_TRADE_THRESHOLD` | Порог для крупной сделки (USDT) | 50000 |

## Риск-менеджмент

- `DRY_RUN=true` по умолчанию — тестируйте без реальных денег
- Максимальная позиция на рынок ограничена `MAX_POSITION_SIZE`
- Cooldown `TRADE_COOLDOWN` между сделками на одном рынке
- Не более 2 сделок за один цикл оценки
- Уверенность модели ограничена диапазоном 15%-85%
- Edge для далёких ценовых целей (>10% от текущей цены) урезается на 50%
- Размер позиции масштабируется по urgency (сила leading-индикаторов)
