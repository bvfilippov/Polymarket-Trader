# Polymarket BTC Trading Bot

Торговый бот для Polymarket, который торгует прогнозами на BTC, используя данные с Binance для генерации сигналов.

## Архитектура

```
Binance API (публичный)
    │
    ▼
┌──────────────────┐
│  binance_data.py │  ← Получает свечи BTC/USDT, считает RSI, MACD, EMA, BB, ATR
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│   strategy.py    │  ← Генерирует сигналы: направление BTC + оценка вероятности
└────────┬─────────┘
         │
         ▼
┌──────────────────────────┐
│  polymarket_client.py    │  ← Ищет BTC-рынки через Gamma API, торгует через CLOB
└────────┬─────────────────┘
         │
         ▼
┌──────────────────┐
│     bot.py       │  ← Главный цикл: данные → стратегия → ордера
└──────────────────┘
```

## Как это работает

1. **Сбор данных** — Бот запрашивает 1h свечи BTC/USDT с Binance (публичный API, ключи не нужны)
2. **Технический анализ** — Рассчитываются индикаторы: RSI(14), EMA(12/26), MACD, Bollinger Bands, ATR
3. **Оценка направления** — Взвешенная модель оценивает вероятность роста BTC
4. **Поиск рынков** — Через Gamma API ищутся активные BTC-рынки на Polymarket
5. **Поиск edge** — Сравнивается наша оценка с ценой на рынке. Если разница > MIN_EDGE — сигнал на сделку
6. **Исполнение** — Ордера размещаются через CLOB API (FOK market orders)

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
# Отредактируйте .env — добавьте приватный ключ кошелька Polygon
```

## Использование

```bash
# Посмотреть текущий анализ BTC с Binance
python main.py snapshot

# Показать активные BTC-рынки на Polymarket
python main.py markets

# Запустить один цикл торговли
python main.py once

# Запустить бота в непрерывном режиме
python main.py run
```

## Конфигурация (.env)

| Переменная | Описание | По умолчанию |
|---|---|---|
| `POLYMARKET_PRIVATE_KEY` | Приватный ключ Polygon кошелька | — |
| `POLYMARKET_FUNDER_ADDRESS` | Адрес кошелька | — |
| `POLYMARKET_SIGNATURE_TYPE` | 0=EOA, 1=Magic, 2=Browser | 0 |
| `MAX_POSITION_SIZE` | Макс. размер позиции (USDC) | 10.0 |
| `MIN_EDGE` | Мин. преимущество для входа | 0.05 |
| `POLL_INTERVAL` | Интервал проверки (сек) | 60 |
| `DRY_RUN` | Режим без реальных сделок | true |

## Стратегия

Модель использует 6 взвешенных сигналов:

| Сигнал | Вес | Описание |
|---|---|---|
| RSI(14) | 2.0 | Перекупленность/перепроданность |
| MACD | 2.0 | Пересечение сигнальной линии |
| EMA cross | 1.5 | EMA(12) vs EMA(26) |
| Bollinger | 1.5 | Позиция в канале |
| Momentum 1h | 2.0 | Краткосрочный импульс |
| Trend 4h | 1.0 | Среднесрочный тренд |

## Риск-менеджмент

- Максимальная позиция на рынок ограничена `MAX_POSITION_SIZE`
- Не более 3 сделок за один тик
- Уверенность модели ограничена диапазоном 15%-85%
- Edge для далёких ценовых целей урезается на 50%
- Режим `DRY_RUN=true` по умолчанию — сначала тестируйте без реальных денег
